For my website you can find the hosted link here: https://tovertafel-dashboard-production.up.railway.app/

The website was created for my final capstone project as a protototype for Tover Health Tech. 
They are a company who build digital games on a device called the "Tovertafel" for people with dementia to help apathy. 
One of the main feedback they got was that the care staff struggle choosing games on the Tovertafel. 
Hence we decided to build a recommendation tool that takes in a bunch of metrics to recommend the perfect game for the resident. 
This is just a prototype and not meant for actual use. 

The other projects in the repository are NLP and other data science projects which I enjoyed doing a lot!!!
